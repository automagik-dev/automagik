Your team, at your desk

Automagik Desktop

Bots that stay, each with its own name, role, model and memory. Talk with them, hand work over and keep the decisions that matter.

Download for

  • Mac.dmg
  • Linux.deb
  • WindowsSoon

Mac with Apple silicon, macOS 13 or newer. Linux on a 64-bit PC.

The real app, with a fictional team and project. The AI’s replies are scripted; the commands, tests and file changes are real.

Two more ways in

Code mode and Team mode.

The app’s switch still says Work for Team mode. Code mode installs separately.

  • Install on Herdr

    Code mode: your code agents in the Herdr window. It needs Herdr and the Automagik pack; the app alone does not set it up.

    Herdr guide ↗

  • Install on DSH

    Already on DeepSeek Harness? Add the Automagik Bot team through its plugin installer.

    DSH guide ↗

Make it yours

Your model. Your files. Your team.

Bring your AI.

Connect an AI account or an API key. Each Bot runs on the model you give it. Omni and an AI account can wait until you are ready.

Keep your files and memory.

The team keeps its files in your computer’s .automagik folder. What Bots read and write goes to your connected AI provider under its terms.

Secrets the Bots never see.

Type keys and passwords into a card in the chat. The Bot never sees the value.

Permission, with clear limits.

It asks before sending as you to a person, deleting something or disconnecting a channel. Main and Omni Bots can read chats and post to groups, WhatsApp channels and your own chat without asking. Other Bots ask for chat access; an Always grant lets them post to that group again.

First steps

Install the app.

Mac

  1. Open Automagik-Mac.dmg.
  2. Drag the Automagik icon to Applications.
  3. Open Automagik from Applications.

Linux

  1. Open Automagik-Linux.deb and choose Install. Or, in a terminal: sudo apt install ./Automagik-Linux.deb
  2. Open Automagik from your apps.

On another Linux, use the AppImage.
